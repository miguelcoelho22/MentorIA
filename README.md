# MentorIA

## O problema

Hoje, estudantes da mesma turma recebem praticamente os mesmos conteúdos e atividades, mas isso não significa que todos tenham as mesmas dificuldades ou aprendam no mesmo ritmo.

Quando olhamos para os dados, percebemos que esse é um problema importante. No PISA 2025, cerca de **7 em cada 10 estudantes brasileiros ficaram abaixo do nível básico de proficiência em Matemática**.

Quando olhamos especificamente para o ensino médio público, o cenário também preocupa. Dados apresentados no **Anuário Brasileiro da Educação Básica** mostram que, em 2023, **menos de 5% dos estudantes da terceira série tinham aprendizagem adequada simultaneamente em Matemática e Língua Portuguesa**.

Foi a partir desse problema que pensamos na **MentorIA**.
